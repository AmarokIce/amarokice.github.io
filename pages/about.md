# 关于我？

这里是初雪冰，一只长居于魔都的北地狼。大多时候都会在家享用咖啡或者睡觉。  
对大多人而言是只怪狼。同时不太喜欢和陌生人交流，并且会对陌生人表露凶相。  
在这世界上还有太多没有嗅闻过的事与物，而我现在仍在努力的嗅闻与学习它们。  
有些老派的作风，并且不喜欢新兴流行的事物，甚至一些时候会觉得新事物很烦。  
很多时候喜欢把文本排版的整齐，虽然这确实没有任何意义，但我还是这么做了。

无论如何，我只是这偌大世界中的一只小狼罢了。

# 关于博客？

和大多数人一样，为了折腾，也为了记录一些什么无聊的东西，然后就开始记录博客了。虽然没有很频繁的更新，但还是会经常回来看看的。

狼与凤梨田的主题与排版，甚至是底层代码都经历过很多轮的迭代。原本我将它设计的就像是一个商业化网站。但这令狼开始思考，我想要的博客就是一个看起来像是产品宣传网站吗？  
之后博客愈发精简，不断的砍掉功能，这甚至让服务器的性能需求越来越低了，甚至是六十块就能租赁一年的廉价服务器都能够支撑的程度。至于现在？这是一个 Github Page——没错，整个网站都是由 HTML 构成的。我认为现在就是我想要的那种精简网站了。

它只是精简了，它的设计与排版还不到我的最佳理想。如果我有空闲时间，我就会尝试去重新设计色卡，设计排版。

还有很远的路。
